# GLOSSARY.md
## Load-Bearing Terms — *Revelations of Divine Love*

This glossary is the operational companion to `STYLEGUIDE.md §6`. It is **living**:
every new term ruling is recorded here the moment it is set, and any ruling that
changes mid-project is amended here *and* flagged for re-review of earlier chapters
(STYLEGUIDE §10).

**Rule of use:** load this file into context before any translation work. Each term
below has a ruling rendering that must be applied consistently. Exceptions require a
`NOTES.md` entry, logged per-instance.

---

## Core Theological Terms

Seeded from STYLEGUIDE §6. Do not silently depart from these.

| Middle English | Ruling Translation | Notes |
|---|---|---|
| *soule* | soul | Not "self" or "psyche" |
| *goostly* | spiritual | Not "ghostly" (misleading) |
| *kinde* / *kindly* | nature / natural | Also carries "kind/kindness" — context determines; **log every ambiguous case** in NOTES.md |
| *homely* / *homeliness* | intimacy / intimate | NOT "homely" (modern meaning is derogatory); consider "familiar" where "intimate" feels too romantic |
| *oneing* | oneing | Retain Julian's coinage; do **not** translate as "union" — she chose a verbal noun deliberately |
| *privy* / *privily* | secret / secretly | Or "inward/inwardly" where *privy* has an interior rather than hidden sense |
| *marvelling* | wondering | Not "marvelling" (too archaic) nor "amazed" (too sudden); "wondering" preserves the sustained quality |
| *courteous* / *courtesy* | courteous / courtesy | Retain; technical and theological (divine condescension-as-nobility) |
| *rest* | rest | Retain; do **not** render as "peace" — Julian distinguishes them |
| *bliss* | bliss | Retain; do not flatten to "joy" or "happiness" |
| *failing* | falling short / diminishing | Context-dependent; **log each instance** in NOTES.md |
| *sensuality* | sensory nature | The bodily-experiential dimension of the soul, not sexuality |
| *substance* | substance | Retain the scholastic term; do not paraphrase |
| *shewing* / *shewings* | showing / showings | Established English rendering; carries revelation-as-gift |
| *motherhood* (of God/Christ) | motherhood | Do not soften or bracket; central to Julian's theology (chs. 57–63) |
| *asseth* / *aseeth* | amends | Satisfaction/reparation for sin (a legal-ecclesiastical term); not "satisfaction" (too forensic) nor "reparation" (too modern). Ratified 2026-06-20 (ch. 1) |
| *wele* / *wo* | weal / woe | Keep the alliterative pair; *wele* = well-being/joy. Ratified 2026-06-20 (ch. 1) |
| *likeing* | delight | Pleasure/gratification; not "pleasure" (too thin) nor "liking" (too weak). Ratified 2026-06-20 (ch. 1) |

## Decisions Added During Translation

> New rulings established as chapters are translated go here, dated, with the chapter
> that prompted them. Keep the tables above authoritative; use this section as the
> running log so the history of each decision is legible.

### 2026-06-20 — ratified from Chapter 1
- ***asseth* → amends** — Julian's term for satisfaction/reparation for sin, both legal
  and ecclesiastical; over "satisfaction" / "reparation".
- ***wele / wo* → weal / woe** — the alliterative pair kept; *wele* = well-being/joy.
- ***likeing* → delight** — over "pleasure" / "liking".
